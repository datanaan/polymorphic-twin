## 演示一：CSTR 化工反应器约束验证

### 场景

一个化学反应器由 6 个传感器监控运行状态，DomainPack 定义了安全边界：

| 参数 | 含义 | 安全约束 |
|------|------|---------|
| `reactor_temp` | 反应釜温度 | ≤ 350°C（**安全关键，超限即紧急停机**） |
| `vessel_pressure` | 釜内压力 | ≤ 15 bar |
| `coolant_flow` | 冷却液流量 | ≥ 5 L/min |
| `feed_rate` | 进料速率 | ≤ 50 L/min |
| `concentration_a` | 反应物 A 浓度 | — |
| `concentration_b` | 产物 B 浓度 | ≥ 1.7 mol/L |

### 关键行为观察

| 正常 → 故障 → 回落 | 系统做了什么 |
|-------------------|-------------|
| 反应器正常运行，温度 200°C 上下 | ✅ Core 逐点验证，约束全部通过 |
| 冷却泵故障，温度开始飙升 | ⚠️ Core 持续监控，冷却流量约束首先标记为 operational 违反 |
| 温度突破 350°C 安全关键阈值 | 🛑 **safety_critical 约束违反，Core 立即中断运行，触发安全回落** |
| 系统进入紧急停机状态 | 📋 所有验证结果写入审计日志，可追溯 |

### 运行方式

```bash
pip install polymorphic-twin
polytwin-cli simulate configs/examples/cstr_scenario.json
```

## 演示二：EvidencePackage 生成与验证

### 场景

SynthGen Core 生成一批传感器模拟数据，打包为 EvidencePackage，经过 Schema 验证确保数据诚实可信。

### 运行结果

```
═══ 实机输出（未修饰）═══

[==========] Running 33 tests from 5 test suites
[  PASSED  ] 33 tests.

EvidencePackage 核心测试:
  ✅ EvidencePackageTest        (2 tests) — 数据结构默认值、字段赋值
  ✅ EvidencePackageJsonTest    (7 tests) — JSON 序列化反序列化、特殊字符、非法输入
  ✅ SchemaValidatorTest       (13 tests) — 数据等级检查、异常检测检查、诚实性检查
  ✅ HashTest                  (3 tests) — SHA256 哈希一致性
  ✅ EvidencePackageBuilderTest (8 tests) — 证据包构建、Schema 哈希、Trace 追踪
```

### SchemaValidator 验证了什么

验证器检查 EvidencePackage 的**诚实性**——如果有人试图篡改数据等级或隐瞒异常，会被检测到：

```
测试: 将 data_grade 设为 "statistically_validated"（不应有的值）
→ 验证器返回: 诚实性违反 (ErrorCode::kHonestyViolation) ❌

测试: 将 exclusion_rate 设为 0.05（但 rows_failed_validation=0 不匹配）
→ 验证器返回: 一致性错误 (ErrorCode::kConsistencyError) ❌

测试: 将 tail_exclusion_statement 设为空
→ 验证器返回: Schema 违反 (ErrorCode::kSchemaViolation) ❌

测试: 合法的 EvidencePackage
→ 验证器返回: 通过 ✅
```

### 运行方式

```bash
cd SynthGen-Core/build
cmake .. && make evidence_package_test
./tests/evidence_package_test
```

## 两者配合：完整的"生成 → 验证"闭环

```
SynthGen Core                Polymorphic-Twin
    │                              │
    │  ① 生成合成数据                │
    │  ② 打包为 EvidencePackage     │
    │     (含 data_grade +          │
    │      provenance + tail_report)│
    │                              │
    │              ────────────────►│
    │                              │  ③ Core 加载 DomainPack 约束
    │                              │  ④ 逐条验证
    │                              │  ⑤ 违反 safety_critical 时
    │                              │     触发安全回落
    │                              │  ⑥ 全部写入审计日志
    │                              │
    │            EvidencePackage    │
    │            ←──────────────── │  ⑦ 返回验证结果
```
