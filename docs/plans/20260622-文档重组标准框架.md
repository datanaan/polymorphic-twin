**p1-bitemporal-expansion.test.ts**:

**p2-evolution-expansion.test.ts**:

- 创建 5 个 CHANGED_IN 边 commit（不含 EVOLVED_FROM）
- 验证 generateEvolutionStory 返回正确内容

**http-routes.test.ts**:

- 新建一个 test/e2e/http-routes.test.ts
- 用 supertest + Express + mock WikiService
- 对每个未测路由测试:
- 成功路径(200 OK + 正确 body shape)
- 缺失 projectId (400 error)
- 缺失其他必填字段 (400 error)
- 无效参数 (400 error)

**mcp-tools.test.ts**:

- 通过 createMcpServer + 模拟 StoreSet 创建 MCP server
- 用 MCP SDK 的 listTools/listResources 遍历工具列表
- 验证每个工具的 name/description 非空
- 不实际调用（需要真实后端）只验证注册

### 关键实现模式

```typescript
// p0a — 测试用例模板
it('skips javascript build dirs (dist, build, .turbo)', async () => {
  expect(paths.has('dist/bundle.js')).toBe(false);
  expect(paths.has('build/output.js')).toBe(false);
  expect(paths.has('.turbo/turbo.log')).toBe(false);
});

it('skips PE binary (MZ magic)', async () => {
  expect(paths.has('bin/app.exe')).toBe(false);
  // Buffer.from([0x4d, 0x5a, ...]) — ELF/PNG 已在原文件测试
});

// p0b — discoverDocs + batchIngest 全链路
it('discoverDocs output feeds batchIngest', async () => {
  const docs = await discoverDocs(repoDir);
  const files = docs.map(d => ({ source_path: d.path, content: readFileSync(...) }));
  const taskId = wikiService.startBatchIngestContent(projectId, files);
  expect(taskId).toMatch(/^batch-content-/);
  expect(wikiService.getActiveTasks(projectId).has(taskId)).toBe(true);
});

// http-routes — 模板
it('POST /api/wiki/ingest returns 200 + taskId', async () => {
  const res = await request(app)
    .post('/api/wiki/ingest')
    .send({ projectId: 'test', source_path: 'doc.md', content: '# Doc' });
  expect(res.status).toBe(200);
  expect(res.body).toHaveProperty('taskId');
});

it('POST /api/wiki/ingest rejects missing projectId', async () => {
  const res = await request(app)
    .post('/api/wiki/ingest')
    .send({ source_path: 'doc.md' });
  expect(res.status).toBe(400);
});
```

## Agent Extensions

### MCP: jelly-code

- **用途**: 在 MCP 工具 E2E 测试中，通过 `[mcp:jelly-code]` 的 `list_repos`、`query`、`search_code` 等工具验证 MCP 层的注册和基础响应。在回归测试中利用 `context` 和 `similar_code` 验证 Neo4j 数据完整。
- **预期产出**: MCP 工具列表验证 31+ 工具正确注册; 回归测试中验证代码图谱数据完整。

### SubAgent: code-explorer

- **用途**: 在实施过程中批量查找文件路径模式、确认所有 import 依赖、验证修改的全局影响。
- **预期产出**: 确保所有新测试文件的 import 路径正确、函数签名与原代码一致。
